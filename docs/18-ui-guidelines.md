# 18. UI方針

## 社員向け

- 今日の勤怠
- 日次勤怠
- 週次勤怠
- 月次勤怠
- 有給残数
- 申請作成
- 自分の申請一覧
- 差戻し対応

## 承認者向け

- 承認待ち一覧
- 勤怠承認
- 申請承認
- 差戻し
- コメント履歴

## バックオフィス向け

- 未処理タスク一覧
- 担当タスク一覧
- 処理ステータス更新
- CSV出力
- 添付ファイル確認
- 完了処理

## 管理者向け

- ユーザー管理
- 権限管理
- 申請種別管理
- カレンダー管理(会社カレンダー本体・年度一覧、月別カレンダーグリッドでの会社カレンダー日
  編集、翌年度への複製、公開前の影響範囲確認)
- 祝日iCalendar同期設定(ソース登録・手動同期・同期履歴・競合解決)
- 勤務形態管理
- シフト管理
- 従業員予定管理(社員別の月間予定表示・個別上書き・休日出勤/振替休日登録・変更履歴)
- 複数従業員予定の一括操作ウィザード(対象範囲・競合ポリシー選択→暫定予定のプレビュー→
  確定適用→履歴からの取消)
- 未割当予定の確認(部署・期間別に`schedule_state=UNASSIGNED`の従業員予定を一覧)
- オンボーディング画面(初回セットアップ時、標準カレンダー自動生成のプレビュー・祝日ソース
  案内・独自休日追加・公開の4ステップ)
- 有給ルール管理
- 監査ログ

暫定予定(一括操作のプレビュー)と確定済みの従業員予定は、色・アイコン(破線枠/実線)で
明確に区別する。保存を伴う操作(会社カレンダー日編集・従業員予定編集・一括操作確定)は
必ず変更理由の入力欄を持つ。
