# 5. ユーザー種別

- 一般社員
- 承認者
- バックオフィス担当者
- 経理担当者
- 総務担当者
- 人事担当者
- システム管理者

承認者は固定ルートだけでなく、申請時に任意の社員を指定できるようにする。

## 会社カレンダー・従業員予定に関する権限

- 会社カレンダー本体・年度の作成・編集・公開・廃止、会社カレンダー日の個別編集、祝日
  iCalendarソースの登録・同期、従業員予定の個別上書き・公開、複数従業員の一括予定変更
  (プレビュー・確定・取消)は、人事担当者・総務担当者・システム管理者のみ行える(いずれも
  本ドキュメントの「管理者」に相当)。一般社員・承認者はいずれも不可。
- 一般社員・承認者を含む全社員は、公開済み(`is_published=true`)の自分の従業員予定のみ
  閲覧できる。他社員の従業員予定の閲覧は管理者のみ可能。
- オンボーディング時の標準カレンダー自動生成は、初回セットアップに限りシステム管理者のみ
  実行できる。
- 一般社員が自分の予定変更を依頼したい場合は、既存の汎用申請ワークフロー
  (`docs/10-usecases-workflow.md`)経由とし、専用の申請経路は持たない。
- API・MCP連携経由の操作も、Web画面と同じ権限チェックを共通のCommandHandlerで通す
  (`docs/25-usecases-integrations-mcp.md`)。
