# ワイヤーフレーム

## 一括操作バー(選択時のみ、表の直上)
PC:
```
[3件を選択中]  [担当者を変更] [完了にする] [その他 ▼]            [選択を解除]
                              └ disabled時: 「自分のタスクのみ完了にできます」
```
モバイル:
```
[3件を選択中]                         [選択を解除]
[担当者を変更] [完了にする] →(横スクロール)
```

## 一括操作ダイアログ(担当者を変更)
```
┌ 担当者を変更 ───────────────────────────┐
│ 選択した3件(未割り当て1件・割り当て済み2件)            │
│ 変更先の担当者 [山田 太郎 ▼]                           │
│ ステータスは変わりません。未着手のタスクは確認中になります。│
│ 新しい担当者と前の担当者に通知されます。                 │
│                        [キャンセル] [3件の担当者を変更] │
└─────────────────────────────────────┘
```

## 一部失敗(ダイアログを開いたまま)
```
┌ 担当者を変更 ───────────────────────────┐
│ 2件を変更しました。1件は変更できませんでした。           │
│ ・名刺申請(佐藤): 完了・取消済みのタスクは担当者を変更できません。│
│ 変更できなかった1件は選択したままです。                  │
│                                           [閉じる]     │
└─────────────────────────────────────┘
```

## トースト(右下、8秒、成功のみ)
```
                                  ┌──────────────────────────┐
                                  │ ✓ 3件のタスクの担当者を山田 太郎さんに変更しました │
                                  └──────────────────────────┘
```

## 確認ダイアログ(取り消せない操作)
```
┌ 申請を承認 ──────────────────────────┐
│ 承認すると取り消せません。申請者に承認の通知が届きます。 │
│                          [キャンセル] [承認する]     │
└───────────────────────────────────┘
```
